# SIET_Placement_Management
Console-based Java SIET Placement Monitoring System with Student/Teacher portals, company management, interview scheduling, and placement tracking.


SIET Placement Monitoring is a Java console application that manages campus placement workflows for students and teachers.
It includes role-based sign-up/sign-in, input validation, company listing and creation, interview scheduling, interview history tracking, and student skill/status updates. 
The project is organized in a feature-based MVP style (View/Presenter/Model) with an in-memory data repository for quick local execution.
